# Netflix Clone

This is a simple Netflix clone created using only HTML and CSS. The project replicates the Netflix homepage layout and design without any backend functionality or JavaScript.

## Features
- Responsive design
- Netflix-style homepage UI
- CSS animations and hover effects
- Mobile-friendly layout

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/krtanay7/Netflix_clone.git
   ```
2. Navigate to the project directory:
   ```sh
   cd Netflix_clone
   ```
3. Open `index.html` in your browser.
